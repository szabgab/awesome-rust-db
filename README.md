# Awesome Rust DB (databases in Rust)

Collecting awesome Rust projects related to databases.

1. Crates to access databases.
1. Crates that implement databases.


## 📂 Database access

- [SQLx](https://crates.io/crates/sqlx) - See the [Awesome SQLx](https://github.com/szabgab/awesome-sqlx) for details.
- [Diesel](https://crates.io/crates/diesel) - See the [Diesel web site](https://diesel.rs/). An ORM.

## 🗂️ Database implementations

- [InfluxDB](https://www.influxdata.com/) - [repository](https://github.com/influxdata/influxdb) - [crate](https://crates.io/crates/influxdb) (2026.02.19)
- [SurrealDB](https://surrealdb.com/) - [crate](https://crates.io/crates/surrealdb) (2026.03.27)
- [sled](https://crates.io/crates/sled) (Latest release 2021.09.12)
- [indradb](https://crates.io/crates/indradb) A graph database written in rust. (Latest release 2025.08.16)
- [FalkorDB](https://www.falkordb.com/) is being rewritten in Rust. See [repository](https://github.com/FalkorDB/falkordb-rs-next-gen)
- [toydb](https://crates.io/crates/toydb)  is a distributed SQL database in Rust, built from scratch as an educational project. (2025.06.01)
- [helix-db](https://crates.io/crates/helix-db) is agraph-vector database built in Rust. (2025.07.16)
- [native_db](https://crates.io/crates/native_db) Drop-in embedded database (2025.07.08)
- [turso](https://crates.io/crates/turso) A high-performance, SQLite-compatible database library for Rust. (2026.04.02)

## Not Database

- [WorkTable](https://crates.io/crates/WorkTable) is in-memory storage. (2026.02.09)
